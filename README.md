# РЕКТОР НИИ (`heuristics-offline-game`)

Массовая оффлайн-игра про управление безумным постсоветским НИИ в мире **Академии «Эвристика»** на механике **Reigns × Lapse: A Forgotten Future** (порог входа — `0,5 секунды`).

## Позвоночник игры

- **Одно движение пальцем (Tinder-свайп влево / вправо)**: на экране одна крупная карта героя (Аркадий Ильич, технарь Гоша, вахтёрша Зинаида Петровна, ревизор Вера Сергеевна, Иржан, орнитолог аэропорта и Профессор N) и одна жизненная дилемма крупным шрифтом.
- **Хождение по канату 4 живых шкал (`💰 Казна`, `🔧 Железо`, `🎯 Спрос`, `🛡️ Порядок`)**:
  - Уронишь в **`0%`** — НИИ отдадут под склад квашеной капусты или опечатают надзором.
  - Перегреешь в **`100%`** — 20 перепрошитых кофемашин Starbucks устроят восстание и уведут корпус к фламинго под Томск, либо бюрократия введёт 96-страничное ТЗ на стаканчик кофе!
- **Цепочки последствий («эффект бабочки»), Музей из 9 иллюстрированных концовок, спасательный Подстаканник `A CUP` и защита на 24-й неделе перед Профессором N.**

## Запуск и сборка

```bash
npm install
npm run build
npm run preview -- --port 4178 --host
```
